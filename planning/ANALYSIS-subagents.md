# pi-subagents faithfulness analysis (2026-09-03)

Question: can pi-subagents 0.64.0 carry pstack delegation without breaking
faithfulness to Lauren's pstack or the local-only requirement?

## Verdict: not a problem. It is the faithful local substrate.

- Native Pi children on the same machine. No cloud, no external service.
- `runs.all` parallel fan-out with standalone briefs, ordered results,
  dropout tolerance (lane blocked, siblings continue).
- `worktree: true` managed git worktrees with in-worktree verification
  gates; parent reviews the aggregate diff. Matches the arena contract.
- Explicit per-run and per-role model pins with documented precedence;
  `inherit` available. Carries role contrast and cross-family judging.
- Read-only agents, tool allowlists, `maxSubagentDepth` fail-closed caps,
  `maxSubagentSpawnsPerRun` bounds, missions with receipts for audit trail.
- Watchdog is opt-in (off by default): no silent second-model behavior.
- Children do not receive the subagent tool by default and get boundary
  instructions; recursion is bounded, never silent.

## Guardrails (normative for our skills)

1. Native agents only: `scout`, `researcher`, `worker`, `reviewer`,
   `oracle`, `delegate`, and our `pstack-*` role agents. Never adapter
   profiles (`claude-code*`, `cursor-agent*`, `codex-exec*`) and never
   external-job providers: those leave local PI or shell to other CLIs.
2. Writers run with `worktree: true` plus a gate; parent merges only the
   selected base on explicit user confirmation.
3. Every launch pins an explicit model. Cross-judge passes must differ in
   family from the author; record which model ran each pass.
4. Setup ensures `maxSubagentDepth >= 2` (flat panels need 1, track
   coordinators need 2). Watchdog stays off unless the user opts in.
5. Missions stay on: receipts are the adjudication evidence trail.

## Fallback (if pi-subagents ever breaks or is absent)

Raw `pi -p` subprocesses via bash: file-based briefs under
`/tmp/<slug>/`, one git worktree per writer, parent aggregates. Fully
local, zero dependencies, no fleet/bounds/gates. Skills keep this text
as the no-extension fallback path.

## Operational notes (verified live)

- Project-local installs require one trust approval (`pi --approve`);
  setup must say so. Untrusted projects silently skip local packages.
- Local-path `pi install` registers the path but does not pull npm
  dependencies. One-shot install needs an npm-published pstack-pi.
- Our 36 role agents (`agents/`, generated by
  `scripts/generate-agents.ts`) discover correctly: 36/36 listed live.
